# Ekylibre

- License: AGPL-3.0
- Stack: Ruby on Rails, PostgreSQL/PostGIS
- Stars: ~476
- Status: active, commercial backing, daily commits
- Origin: France

## What it is

Ekylibre is a heavyweight all-in-one FMIS combining accounting, ERP, agronomy, and GIS. Targeted at commercial farms and cooperatives, particularly in the EU.

## Mobile + desktop story

- **Mobile**: responsive web only
- **Desktop**: web (Docker deploy)

## Strengths

- Most complete feature set among OSS FMS (financial integration is class-leading)
- Active commercial maintenance
- Strong EU/CAP compliance fit

## Weaknesses

- Heavyweight Rails stack; not appropriate for offline mobile
- French-first; English docs lag
- Server-required architecture

## Relevance to herd-scout

Reference for "OSS FMS that natively does P&L per enterprise" — a feature gap that farmOS punts on. Ekylibre proves it's feasible in OSS.
