# LiteFarm

- License: GPL-3.0
- Stack: TypeScript/JavaScript, Node.js + PostgreSQL/PostGIS, React PWA
- Stars: ~217 (but >17k commits on integration branch)
- Status: actively deployed in NA/LatAm; 2026 commits ongoing
- Backing: not-for-profit, UBC-led

## What it is

LiteFarm is a mobile-first PWA farm management system for diversified small farms with explicit sustainability/organic focus. Modules cover certification tracking, ecosystem-services payments, tasks, crops, finance.

## Mobile + desktop story

- **Mobile**: mobile-first PWA at app.litefarm.org. No native iOS/Android.
- **Desktop**: same PWA. No separate desktop app.

## Strengths

- Modern JS stack (vs farmOS's Drupal)
- Sustainability/certification angle differentiates from farmOS
- Multi-language (NA/LatAm deployments)
- Active 2026 commits

## Weaknesses

- Smaller user base than farmOS
- No native mobile (offline PWA only)
- No drone/imagery integration

## Relevance to herd-scout

Reference for "modern stack OSS FMS" — but still PWA-only. The native-mobile + offline-first + drone-vision combo remains an unfilled niche.
