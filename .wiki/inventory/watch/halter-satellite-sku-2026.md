# Watch: Halter satellite SKU 2026

## Why this is on the watch list

Halter is the only commercial vendor with rich animal-level real-time data (solar collars + virtual fencing) AND a satellite-connected, low-infra deployment story for beef ranches. The 2026 satellite SKU expands their reach into the connectivity-poor extensive-grazing markets that the herd-scout offline-first / P2P pitch currently owns by default. If Halter opens a counting/analytics API or launches a "lite" software-only tier, they erode the offline differentiator.

## Watch triggers

Re-evaluate when any of:

- Halter releases a public API or developer program
- Halter launches a software-only tier (collars optional)
- Halter announces a CV / drone-counting partnership or in-house SKU
- A Halter-Soilworks / Halter-AgriWebb / Halter-Merck integration appears
- Pricing for the satellite SKU is published (signal of commitment / market sizing)

## Cadence

Quarterly check on https://www.halterhq.com/ press, integrations, and developer pages. Add to the next `/wiki:research --thesis` if any of the above trigger.
